# AI Security: The S in MCP Stands for Security

## Abstract

As AI assistants gain access to our emails, codebases, and databases, we're one prompt injection away from disaster. This session explores the "Lethal Trifecta" — the architectural flaw that makes AI systems fundamentally vulnerable — through real-world breaches including zero-click data exfiltration and RCE via code comments. You'll learn attack patterns (tool poisoning, multimodal injections) and defensive strategies including tool isolation and prompt injection detection. Walk away knowing which AI integrations are safe and which are ticking time bombs.

## Target Audience

Developers, security engineers, and architects building or integrating AI-powered tools.

## Key Takeaways

- Understand why prompt injection is "unfixable" at the architecture level
- Identify the Lethal Trifecta (private data + untrusted input + exfiltration) in your systems
- Apply mitigations: tool isolation, CSP hardening, guardrails
- Evaluate MCP servers for common vulnerabilities (43% have command injection)

## Session Format

45-60 minutes (adjustable)
